AUGUST 17, 2026, MORNING

[!] "Image generation is not working, it says connection hiccup." FOUND, and it
    was not the connection. Since projects live in the cloud, a card's picture
    is an address, not the picture. The browser will DRAW such a picture but
    refuses to let MAYA read its bytes back unless the storage bucket says it
    may, and the bucket never said so. Visualize and Modify need those bytes,
    because the previous picture is the anchor for the new one. So every render
    on a saved project failed, and the honest network message came out as
    "connection hiccup". Fixed in v13.26: MAYA reads its own pictures through
    its own server whenever the browser refuses, so this can never stop a
    render again. Setting the bucket rule is still worth doing once, and it is
    one command, in fixes.txt dated today.
