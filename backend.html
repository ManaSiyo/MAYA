3D · how it's made
Three.js four-plane turntable (cube)
The three-view atelier sheet from gpt-image-1.5 is sliced into four UV-mapped planes around a vertical axis. Drag to orbit. Press "Render in 3D" to swap this placeholder for a real photoreal mesh from fal.ai's Hyper3D Rodin.

Pattern · how it's made
OpenAI gpt-image-2 · CLO3D-look flat pattern
A technical-drawing-style raster is generated from the dream-garment image. Warm-white paper, dashed grainline arrows, triangular notches at every seam pair, faint seam-allowance offset 1 cm inside the cut edge, true-to-fabric proportions, marker-sheet layout.
Stage: decorative reference · upgrade path: GarmentCode JSON + PyGarment (Phase B)
Swipe back to Pattern first, the vector is built from whatever the dissect call returns.
Vector · how it's made
ImageTracer.js · raster → SVG with waist anchor
The Pattern raster is traced into SVG paths in-browser. Light strokes on translucent paper for cosmos contrast. The whole drawing is then scaled so its natural width equals the client's waist measurement in cm, the v0.14 physics anchor. Scroll to zoom · drag to pan · Upload your own SVG / PLT to override.
Library: ImageTracer.js · v1.2.6 · public domain · runs entirely in the browser
Drop pattern panels (SVG or PLT) anywhere here, or add them from the menu, Maya nests them automatically against the X/Y bed in Settings.
Nest · how it's made
Bounding-box bottom-left fill · pure JS in this file
Each SVG / PLT panel is parsed for its bounding box in cm. Panels are sorted by area descending, then placed at the lowest-leftmost corner that fits, trying 0° / 90° / 180° / 270°. Sheet width is the X dimension from Nest config; spacing acts as the laser-kerf buffer. Upgrade path: true No-Fit-Polygon (SVGnest core) for 90%+ utilization.
Algorithm: bbox bottom-left · ~150 lines of in-house JS · 0 dependencies
