Connecting what is missing
Manasiyo.com visitors, from Wix itself. Make an API key at manage.wix.com/account/api-keys (permission: Site Analytics, or All site permissions), then set it as WIX_API_KEY on the maya-api service in Cloud Run. The key is a credential: paste it yourself, in the Cloud Run console. The site is already pinned in the server; override with WIX_SITE_ID only if the site ever changes. A minute after the deploy, the tiles above fill with the same numbers the Wix dashboard shows.

The two MAYA tables below them read MAYA's own Analytics with the Cloud Run identity (the service account is already a Viewer on pro-maya).

Leads, from the site's own forms. The lead list reads Wix Forms directly with the same WIX_API_KEY. If it ever says not connected, the key was made with only the Site Analytics permission: make a new key at manage.wix.com/account/api-keys with All site permissions (or add Forms read), then replace WIX_API_KEY on Cloud Run yourself.

Windsor, for the paid chart above. One key fills Google Ads and Meta together: windsor.ai → API Keys → copy the key → set it as WINDSOR_API_KEY on the maya-api service in Cloud Run. The key is a credential: paste it yourself, in the Cloud Run console.

Meta ads. A long lived access token and the ad account number, set as META_ADS_TOKEN and META_AD_ACCOUNT_ID on the API. The token is a credential: paste it yourself, in the Cloud Run console.

Google ads. Needs a developer token from Google, which is applied for and takes a few days, plus an OAuth client. Set GOOGLE_ADS_DEVELOPER_TOKEN, GOOGLE_ADS_CLIENT_ID, GOOGLE_ADS_CLIENT_SECRET, GOOGLE_ADS_REFRESH_TOKEN and GOOGLE_ADS_CUSTOMER_ID. Until then this page says not connected rather than inventing numbers.
