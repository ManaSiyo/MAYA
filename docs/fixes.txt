AUGUST 27, 2026, OPEN MAYA'S DOOR (v14.02, after the push)

Maya's MCP server is live at POST https://maya.manasiyo.com/mcp once v14.02 is
deployed, but it stays CLOSED (503) until a token exists. Two green steps.

🟢 1. Make a token and set it on Cloud Run.
   Any long random string works (32+ characters, letters and digits). Open
   https://console.cloud.google.com/run/detail/us-west1/maya-api/revisions?project=pro-maya
   then "Edit & deploy new revision" > Variables & Secrets > Add variable:
   name MAYA_MCP_TOKEN, value = the token. Deploy. Keep the token somewhere
   private; it is the only key to the door.
🟢 2. Add Maya to Claude as a custom connector.
   claude.ai > Settings > Connectors > Add custom connector. Name: Maya. URL:
   https://maya.manasiyo.com/api/mcp?token=YOUR_TOKEN (the query form exists for
   connectors that cannot send a header; /api/mcp is the address, the bare /mcp
   only works from v14.05 on). Save. In any chat or Cowork
   session, Maya's eight tools appear (maya_soul, maya_inbox, ...).
   Claude Code / Codex: same URL as an MCP server of type http.

Check it worked: ask Claude "read maya_status". It answers with the version
and the number of open feature requests. If you see maya_door_closed, the env
var did not land; if unauthorized, the token in the URL does not match.
