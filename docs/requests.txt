MAYA REQUESTS
Fromsa's own log. What HE asked for and what HE noticed, in his words,
simplified, with date and time. Not what Claude did (that trail lives in
commits and fixes.txt). Say "log the request" in any chat and Claude adds
the entry from the prompt just given. Newest on top.

How the four text files divide the work:
  README.md     the manual. Architecture, deploys, data, how to work here.
  history.txt   the story. What happened, in narrative, dated.
  fixes.txt     fix attempts, especially ones outside git (Cloud Run,
                Google console, credentials). Symptom, cause, action, status.
  requests.txt  this file. Fromsa's requests and the bugs he notices, so
                every ask can be checked later: done or not, and whether a
                fixed thing broke again.

Each entry: date and time of the prompt, then the asks as short lines.
Status marks: [ ] requested   [x] done   [!] recurred after being fixed.
