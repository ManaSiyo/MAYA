# MAYA codebase audit, Aug 27 2026 (v14.02)

Scope: the whole repository as of v14.01, read file by file with `git ls-files`
and sizes. Verdicts: KEEP (serves the product), COLD (kept for the record,
nothing reads it), DELETE (safe to remove, Fromsa's call), DEBT (structural,
worth a plan).

## The two big ones

1. DEBT: `frontend/index.html` (17,035 lines) and `playground/index.html`
   (17,314 lines) are the same app twice. Every fix has to be made in both,
   and the playground carries a growing addon tail. The honest fix is one
   source: `frontend/index.html` plus a `playground/addon.html` fragment, with
   a tiny build step (a Node script in tests/) that writes
   `playground/index.html` = frontend + addon before every commit, and a test
   that asserts they only differ by the addon. The handoff rule "never
   regenerate the playground as frontend plus badge" was about not losing
   experiments; the addon file IS where the experiments live, so the rule is
   kept. Not done tonight: it changes every future workflow and Fromsa should
   choose the moment.
2. DEBT, fixed tonight: `docs/AI-HANDOFF.md` was 2,160 lines of history in a
   file whose own first line says it is a state file. Trimmed to ~210 lines;
   v13.24 through v13.98 moved to `docs/archive/AI-HANDOFF-through-v13.98.md`.

## Code level, inside the big files

- `playground/index.html` addon tail (from line ~17,000): zoom v5 (rewritten
  tonight), backgrounds, screen order, badge placement. Clean.
- Old zoom code is fully gone (`parkVoiceBar`, screen pinning, the
  `#screen-inspo` transition); the regression suite asserts their absence.
- `docs/server/server.js` (3,900 lines) is one file with ~50 routes. It works
  and it is tested by smoke + regression source assertions. The pure modules
  pattern (`admin-command.mjs`, `proxy-policy.mjs`, `maya-mcp.mjs`) is the
  right direction: next candidates to extract are the Maya memory/soul/people
  stores (~150 lines) and the lead station (~250 lines).
- Duplicate strings: `'Turn on Hey Maya'` is gone; the two wake toggles
  (`#wake-toggle` in the command head and `#maya-toggle` at the floor) share
  `_wakeLabel()` which is fine.
