## Findings in priority order

1. **Outbound calls depend on one server instance.** maya-phone.mjs placeCall,
   outboundTwiml and stream start share an in-memory outbound map. A different
   instance/restart can reject a legitimate callback or lose mode/reason. Persist
   call state, include pending calls in concurrency limits and collect call status.
2. **Phone request storage can lose prior items.** server.js loadMayaFeatures
   turns read errors into an empty inbox; the next append can overwrite history.
   Locks are per process, not across Cloud Run instances. appendMayaFeatureFrom
   tags the last row in a separate write, so simultaneous requests can lose source
   attribution. Use conditional writes and one atomic record per request.
3. **Messages draft is incomplete.** Blocking guards Admin sends/calls and incoming
   SMS, but incoming voice never checks it. Deleted blocked threads are hidden with
   no blocked-contacts view to unblock them. Delivery callbacks arriving before the
   outbound row is saved are discarded. These need tests before release.
4. **Names enter inline JavaScript.** status.html paintThreads inserts contact names
   into onclick strings with HTML-only escaping; apostrophes break the action and
   crafted names can alter the handler. Bind events without interpolated code.
5. **SMS user feedback is inconsistent.** The UI says it waits for a consent reply,
   but send route does not enforce that waiting state or create a consent question.
   UI also ignores the new history-save warning returned after carrier acceptance.
   Define accurate conversational messaging behavior and keep STOP enforcement.
6. **Owner calls missing from Messages.** finish explicitly excludes admin/brief
   calls from onCallEnd. Full transcripts are stored separately but there is no
   Admin transcript viewer or unified request/action outcome timeline.
7. **Owner authentication depends on caller ID.** No second factor protects owner
   phone reads/writes. Verify identity more strongly before adding costly ad actions.
8. **Voice latency and accounting remain unmeasured.** AI socket opens at stream
   start; early audio may be dropped; interruption clears playback without removing
   unheard speech from context. No measured first-audio latency or per-turn usage.
   Local meter charges one flat amount per session. Lead summaries add cold-read
   latency and some bypass spending accounting.
9. **Marketing can misstate facts.** Windsor warning rows are treated as campaigns;
   ticker can infer ads are paused when reporting is unavailable. Current live
   Google chart has data again; the earlier limit incident is not proof of a
   continuing total outage. Ticker calls cost per click CPL. Missing ad feeds can
   be counted as zero in blended CPL. No campaign-to-paid-order attribution.
10. **Tier edit mismatch in draft.** New pill displays tier before company but saves
    company; a later refresh can restore the old tier. Verify canonical tier write.
11. **Request workflow does not close the loop.** log_note saves a feature wish;
    it does not create a scheduled job, execute an action, or verify a shipment.
    Requests need requested/approved/in-progress/verified/shipped states and links
    to evidence. A push alone should not erase uncompleted requests.
